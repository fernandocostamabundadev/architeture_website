# Atelier Norte — arquitetura

Página de apresentação responsiva para um atelier de arquitetura, feita com HTML, CSS e JavaScript sem dependências externas.

## Pré-visualização

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático local.

## Funcionalidades

- Layout adaptável a telemóveis, tablets e computadores.
- Navegação mobile com suporte para teclado e leitores de ecrã.
- Carrossel de projetos com controlos acessíveis e atualização dinâmica do ano.
- Imagens locais, carregamento otimizado e suporte para preferência de movimento reduzido.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `assets/css/styles.css` — estilos e regras responsivas.
- `assets/js/main.js` — carrossel e navegação mobile.
- `assets/img/` — imagens e ícone do site.
